# 贴图交付清单

给生图工具（Codex 等）用的规格。文件生成后直接放进本目录，文件名照表里的来。

游戏这边会做成“有图用图、没图用现在的程序化效果”，所以可以分批交付，不用一次凑齐。
**建议先出这五张看整体效果**：`snow`、`concrete_panel`、`brick`、`facade_block`、`facade_ruin`。

贴图能改善的是墙面、雪地、金属、木头的质感；人物和道具由方块拼成这一点，要靠另外加几何细节来解决。

## 通用要求

- **格式**：PNG，sRGB，不要透明通道（标注“带透明”的除外）。
- **视角**：正对表面的平拍，无透视，无烘焙阴影，无高光，光照均匀。游戏里的光影由引擎来打。
- **色调**：偏灰、低饱和、中等明度，不要纯黑纯白。夜景调色会再压暗，贴图本身太暗会糊成一片。
- **不要文字**：生图模型写不好中文，标语和招牌在游戏里用字体叠上去。
- **总量**：全部加起来控制在 8MB 以内（网页版单文件有上限）。

## B. 建筑立面模块（1024×1024，左右和上下都要能拼接）

一张图是“一个开间 × 一层楼”，游戏里按楼的长度和层数重复铺。

**窗户的位置必须固定**，这样亮灯和雾效才能对上：

- 窗洞居中，宽占画面的 50%（左右各留 25%）。
- 窗洞高占画面的 50%（下边留 28%，上边留 22%）。
- 画面四边是板缝的一半，拼起来正好是一条完整的缝。

| 文件名 | 内容 |
| --- | --- |
| `facade_block.png` | 住人的板楼：灰白预制板，木窗框，玻璃是深色（灯光由游戏来加） |
| `facade_husk.png` | 停暖的空楼：同上，但玻璃破损、窗框歪斜、墙面更脏 |
| `facade_ruin.png` | 废墟：没有窗框，窗洞是空的，**窗洞区域做成透明**（带透明），墙皮大片剥落 |
| `facade_factory.png` | 厂房：红砖，高窄的工业窗，铁窗棂 |
| `facade_stripe.png` | 选矿厂：蓝白横条纹的金属墙板，小方窗 |
