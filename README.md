# Medusa · 维斯珀港（Vesper Harbor）

一个 **Godot 4.3+** 的等轴透视（isometric）侦探 RPG Demo，在美术和玩法上借鉴了《极乐迪斯科》的风格：
油画质感的画面、黎明前的雨夜港口、会和你说话的“内心技能”、2d6 技能检定，以及大段的文字对话。
所有内容（场景、角色、剧情）都是原创的，没有使用任何外部美术资源，全部由几何体和着色器程序化生成。

## 运行

1. 用 Godot **4.3 或更高版本** 打开本目录（`project.godot`）。
2. 按 F5 运行（主场景：`res://scenes/main.tscn`）。

项目使用 **Compatibility（OpenGL）** 渲染器，集显/老显卡也能跑。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键点击地面 | 移动（自动寻路） |
| 双击 | 奔跑 |
| 左键点击人物/物件 | 走过去并交互 |
| 按住 Tab | 显示所有可交互物 |
| 鼠标滚轮 | 缩放镜头 |
| 1–9 | 选择对话选项 |
| 空格 / 回车 / 点击对话框 | 跳过打字动画 |

## 玩法内容

- **主线**：你在长椅上醒来，失去了记忆。目标是“找回你的名字”。
- **NPC 锚叔**：守着火桶的老码头工，可以问话、做逻辑检定（推断职业）和共情的红色检定（一次性）。
- **可交互物**：电话亭、积水倒影、木箱（藏着一瓶酒：喝掉还是扔进海里？）、会说话的路灯、旅馆大门、长椅。
- **六种技能**，分四类颜色：逻辑（智力）、共情 / 直觉 / 意志（心智）、渴求（体魄）、感知（运动）。
- **主动检定**：选项上显示 `[技能 - 难度 DC] 成功率%`，掷 2d6 + 技能值 ≥ DC 即成功（双 6 必成，双 1 必败）。
- **被动检定**：走进某些区域或读到某些台词时自动检定，成功了内心的声音才会开口。
- **健康 / 士气、物品、念头、任务** 通知。

## 画面风格是怎么做的

| 效果 | 实现 |
| --- | --- |
| 等轴视角 | `camera_rig.gd`：正交相机，俯角 35.264°、偏航 45°，平滑跟随 + 滚轮缩放 |
| 油画质感 | `shaders/painterly.gdshader`：全屏 Kuwahara 滤波（色块笔触）+ 笔触扰动 + 墨线 + 冷暖分级 + 画布纹理 + 暗角 |
| 手绘表面 | `shaders/painted.gdshader`：世界坐标噪声的色彩变化、竖向雨渍、墙根积垢 |
| 湿漉漉的街道 | `shaders/cobbles.gdshader`：程序化鹅卵石 + 积水区域低粗糙度反光 |
| 海水 | `shaders/water.gdshader`：顶点起伏 + 法线扰动 |
| 氛围 | 冷色月光 + 暖色路灯/火桶/窗户点光源、闪烁霓虹招牌、雨粒子、雾、Glow |

## 项目结构

```
scenes/main.tscn            主场景（环境、灯光、导航区域、可交互物、被动检定区、玩家、相机、后处理、UI）
scripts/
  game_state.gd             Autoload：技能、2d6 检定、旗标、物品、健康/士气
  dialogue_db.gd            全部对话数据（节点 / 台词 / 选项 / 检定 / 效果）
  dialogue_panel.gd         右侧对话面板（日志、打字机效果、选项、检定结算）
  ui.gd                     HUD、通知、被动检定低语、悬停名称
  main.gd                   鼠标拾取、导航烘焙、对话开关、开场
  player.gd                 点击移动（NavigationServer3D 寻路）
  interactable.gd           可交互物基类（名称、对话 ID、交互距离、悬停标记）
  passive_zone.gd           走入即触发的被动技能检定
  character_visual.gd       @tool：几何体拼出的风格化人物 + 走路动画
  level_builder.gd          @tool：程序化搭建整个港口场景（编辑器里也可见）
shaders/                    上面提到的四个着色器
```

## 扩展

- **加对话**：在 `scripts/dialogue_db.gd` 里加节点；文件顶部注释说明了所有字段（`requires`、`check`、`set`、`effects`、`goto` 等）。
- **加可交互物**：在 `NavRegion/Interactables` 下复制一个节点，修改 `display_name`、`dialogue_id` 和碰撞形状（collision layer 2）。
- **加被动检定**：复制 `PassiveZones` 下的 Area3D，改技能、难度和文本。
- **调画风**：选中 `PostFX/Painterly`，在材质参数里调笔触半径、墨线强度、饱和度、暗角等。
- **调人物外观**：选中任意 `Visual` 节点（`character_visual.gd`），在检查器里改风衣/帽子/围巾颜色，编辑器里实时更新。
