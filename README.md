# Medusa · 霜原-7

一个 **Godot 4.3+** 的等轴透视（isometric）叙事 RPG Demo：油画质感的画面、会和你说话的“内心技能”、2d6 技能检定、大段的文字对话。
世界观是**苏联朋克**——极夜里的矿镇，没有屋顶的预制板楼，冒着蒸汽的热电厂，红底奶油字的宣传牌，会广播的喇叭，半埋在雪里的步行掘进机。
所有内容都是原创的，没有外部美术资源，场景全部由几何体和着色器程序化生成。

在线试玩（Web 导出）：https://claude.ai/artifact/9b4rjffxiJbd3i3o6yM6cM

## 世界

你是国家建筑普查委员会派来的普查员，在第七矿镇“霜原-7”的候车亭里醒来，不记得自己的名字。
你带来的《建筑编号索引》上有 B001–B132 一共 132 个编号，可镇子里只有 127 栋楼——**剩下 5 个原轮廓画在了边界外面**。

镇子的布局来自 `data/buildings.json`，和索引图是同一套坐标：西区斜向的长条板楼、中央大街两侧的无顶废墟、东区还住着人的楼；沿大街往北是热电厂和选矿厂。

> 现在的 `buildings.json` 是照着索引图**目测誊写**的（85 个轮廓），位置、尺寸和朝向都是近似值。
> 文件格式很简单（`id / x / z / len / wid / rot / kind / floors`，单位米），可以直接用真实的建筑数据替换，场景和地图会跟着变。

## 运行

1. 用 Godot **4.3 或更高版本** 打开本目录（`project.godot`）。
2. 按 F5 运行（主场景：`res://scenes/main.tscn`）。

项目使用 **Compatibility（OpenGL）** 渲染器，集显/老显卡也能跑。

### 导出 Web 版

仓库里带了 `export_presets.cfg`（Web，无线程版，不需要 COOP/COEP 头）。安装好 4.3 的导出模板后：

```
godot --headless --path . --export-release Web build/web/index.html
```

中文显示用的是随项目打包的 `fonts/NotoSerifSC-subset.ttf`（思源宋体的子集，含 ASCII、常用标点和 GB2312 一级常用字，OFL 许可），
所以浏览器里不依赖系统字体；桌面端缺字时会回退到系统字体。

## 玩法内容

- **主线**：找回你的名字。线索从火桶边的老司炉开始，通到十字街东边的终端亭。
- **可交互物**：老司炉（炉叔）、公用终端亭、冰面上的倒影、配给箱（里面藏着一瓶酒）、会说话的广播喇叭、文化宫大门、候车亭长椅、建筑编号索引牌、宣传牌、纪念碑，以及大街北段的步行掘进机“猛犸-2”。
- **六种技能**，分四类颜色：逻辑（智力）、共情 / 直觉 / 意志（心智）、渴求（体魄）、感知（运动）。
- **主动检定**：选项上显示 `[技能 - 难度 DC] 成功率%`，掷 2d6 + 技能值 ≥ DC 即成功（双 6 必成，双 1 必败）。
- **被动检定**：走进某些区域或读到某些台词时自动检定，成功了内心的声音才会开口。
- **健康 / 士气、物品、念头、任务** 通知。

## 画面是怎么做的

| 效果 | 实现 |
| --- | --- |
| 等轴视角 | `camera_rig.gd`：正交相机，俯角 35.264°、偏航 45°，平滑跟随 + 滚轮缩放 |
| 油画质感 | `shaders/painterly.gdshader`：全屏 Kuwahara 滤波 + 笔触扰动 + 墨线 + 冷暖分离调色 + 画布纹理 + 暗角 |
| 预制板楼立面 | `shaders/building.gdshader`：按层数和开间程序化生成窗洞、板缝、亮灯的窗、厂房色带、窗台积雪和墙面的霜；每栋楼只是一个盒子 |
| 雪原 | `shaders/snow.gdshader`：风吹出的雪垄、压实的道路和车辙、冰晶反光 |
| 手绘表面 | `shaders/painted.gdshader`：色块化的明暗、冷暖色偏、斜向笔触 |
| 人物被挡住时的镂空 | 相机始终对着人物，建筑着色器把画面中心附近、比人物离相机更近的墙抖动丢弃 |
| 静态合批 | `level_builder.gd` 的 `_merge_static()` 把共用同一材质的零碎网格合并成一个。Web 上的 Compatibility 渲染器在网格实例超过一千个左右时会整帧不出图，合并后全镇只有约 400 个 |
| 氛围 | 低角度的暖色日光 + 冷色天光、火桶和终端的点光源、烟囱蒸汽、飘雪、航空障碍灯、雾、Glow |
| 界面 | 红、奶油、墨黑三色的色块和斜条：工作证式的角色卡、笔录式的对话面板、电报式的通知 |

## 项目结构

```
data/buildings.json         建筑轮廓（索引图坐标，单位米）
scenes/main.tscn            主场景（环境、灯光、导航区域、可交互物、被动检定区、玩家、相机、后处理、UI）
scripts/
  town_data.gd              读取 buildings.json，索引图坐标 ↔ 世界坐标
  level_builder.gd          @tool：程序化搭建整个矿镇（编辑器里也可见）
  map_view.gd               按 M 打开的建筑编号索引地图
  game_state.gd             Autoload：技能、2d6 检定、旗标、物品、健康/士气
  dialogue_db.gd            全部对话数据（节点 / 台词 / 选项 / 检定 / 效果）
  dialogue_panel.gd         右侧对话面板（日志、打字机效果、选项、检定结算）
  ui.gd                     HUD、通知、被动检定低语、悬停名称
  main.gd                   鼠标拾取、导航烘焙、对话开关、开场
  player.gd                 点击移动（NavigationServer3D 寻路）
  interactable.gd           可交互物基类（名称、对话 ID、交互距离、悬停标记）
  passive_zone.gd           走入即触发的被动技能检定
  character_visual.gd       @tool：几何体拼出的风格化人物（大衣、护耳帽、围巾）+ 走路动画
  fonts.gd                  打包字体 + 系统字体回退，按字重生成字体变体
shaders/                    上表提到的着色器，外加光锥和对话面板底色
```

## 扩展

- **换成真实的建筑数据**：替换 `data/buildings.json`。`origin` 是世界原点（十字街口）在索引图上的坐标，`scale` 是米到游戏单位的比例。
- **加对话**：在 `scripts/dialogue_db.gd` 里加节点；文件顶部注释说明了所有字段。
- **加可交互物**：在 `NavRegion/Interactables` 下复制一个节点，修改 `display_name`、`dialogue_id` 和碰撞形状（collision layer 2）。
- **加被动检定**：复制 `PassiveZones` 下的 Area3D，改技能、难度和文本。
- **调画风**：选中 `PostFX/Painterly`，在材质参数里调笔触大小、墨线强度、饱和度、暗角等。

注意相机是从东南上方往西北看的，只有朝南和朝东的立面看得见，招牌和门要放在这两个朝向上。
